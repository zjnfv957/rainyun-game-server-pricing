## 你租的是整台机器，还是一个开服面板

这是最容易被忽略的第一道岔路，选错了后面全白算。

**VPS / 云服务器型**：平台给你 root 或管理员权限，一块独立（或 NAT 共享）的公网 IP，系统自己装、Java 自己配、服务端自己传。好处是自由——端口想开就开、多开服务端、装插件、跑非游戏程序都行。代价是环境得自己折腾。

**面板服型**：平台给一个网页面板，通常基于翼龙面板、MCSM 或者自研面板，点几下就能开服，甚至能一键切换 CPU 机型。缺点是环境被限制在指定镜像里，能改的东西有限。

雨云游戏云这两类都提供了：VPS 服务器、雨云自研面板、MCSM 面板三种入口。单开一个 Minecraft 服，面板服更省事；要同时跑几个服务端，或者打算装点别的东西，就走 VPS。

## 决定账单的其实是计费方式，不是套餐名字

大多数平台把注意力都放在"几核几 G"上，但真正让账单失控的是计费模式。

- **固定计费**：按你买的规格收固定月租，开不开机都是这个价。
- **动态计费**：底价月租很低，然后按 CPU 实际超额使用情况每日结算。雨云的做法是给一个"CPU 电量"概念——CPU 使用率低于 20% 视为不耗电，超过 20% 的部分才计费，内存、硬盘这些不产生电量费用。公开整理的单价数据里，E5-2666v3 这类低频机型大约 0.0005 元/电量，Ryzen 5900X 约 0.0008 元/电量，9950X、7950X、14900K 这类高频机型约 0.001 元/电量。

取舍很简单：服务器每天在线超过两小时，长期稳定跑，固定计费更省心也不用担心高峰账单；只是每周和朋友玩两三个晚上、白天基本闲置，动态计费能砍掉一大截闲置成本。雨云官方选购文档里写得很直白——两种模式在计费项目上差别不大，价格主要由 CPU、内存、硬盘、IP 这些资源配置决定。

> 一个容易踩的坑：动态计费的低月租是"基础租金"，不是最终价。如果你把视距拉满、装了二百个模组、每天在线六小时，动态计费最后很可能比固定计费还贵。反过来也一样，固定计费买个高配常年闲置，等于替机房交电费。

## 下单前把这几件事确认掉

租游戏服务器的坑，九成不在配置上，而在这几个地方：

- **续费价**。很多平台的低价只针对首购，第二年直接翻倍。看年付价，不要只看首月价。
- **IP 和端口类型**。NAT 共享 IP 只能用映射端口，独立 IP 要加钱。你要跑的服务端需不需要独占端口，先想清楚。
- **扩容单价**。硬盘 1 元/GB/月、带宽按 Mbps 加钱，这些增量成本会在你玩到第三个月、存档变大时冒出来。
- **防御是否共享**。共享防御意味着别人被攻击时你可能被顺带限速。
- **备份策略**。能不能自助创建备份、能不能定时备份，决定了你哪天手滑删错存档之后是哭还是笑。
- **退款规则**。七天无理由退订是真的，但有次数限制，年付前先跑一段月付更稳。

## 常见问题

**面板服和 VPS 该选哪个？**
新手单开一个服，面板服更省事；要跑多个服务端、装 SFTP 传大存档、或者需要完全控制环境，选 VPS。

**动态计费会不会最后比固定计费还贵？**
会，如果 CPU 长期高负载。它的设计目标是省闲置成本，不是省峰值成本。CPU 使用率长期压在 20% 以下才划算。

**画面上写着"可承载 25 人"，是保证 25 人同时在线不卡吗？**
不是保证值，是官方给的参考基准，而且明确标注了视距和 mod 数量前提。版本越高、mod 越多、视距拉得越大，实际能承载的人数就越少。服务端 TPS 掉下来的时候，第一反应应该是降视距和减实体，而不是先怀疑机器。

**能不能先买一个月试试？**
可以，而且建议这么做。首月 5 折券 + 1 元试用 + 七天无理由退订这套组合，本来就是给"先验证再长付"准备的。
